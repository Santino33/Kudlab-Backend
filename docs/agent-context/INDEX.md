# Contexto técnico para agentes

Esta capa resume `docs/original/` para preparar especificaciones SDD; no equivale a `spec.md`, `plan.md` ni `tasks.md`. Leer [contexto](project-context.md), [arquitectura](architecture-summary.md), [decisiones](decisions.md) y [pendientes](unresolved-issues.md), después módulo y feature. Para cualquier identificador RF indicar **fuente y versión**: RF del análisis, del diseño y de V3 no son intercambiables. «Documentado» no significa aprobado ni implementado.
