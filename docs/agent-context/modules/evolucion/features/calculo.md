# RF-017 (V3, propuesta): calcular indicadores de tareas

**Actor:** sistema tras sesión con eventos válidos. Propósito: convertir registros en indicadores de su ficha por tarea, sin inventar puntuación global. [V3 RF-017](../../../../original/requisitos_V3.xlsx), [F §5 pp. 42–50](../../../../original/Fundamento%20teorico.docx.pdf), [procesamiento JPEG](../../../../original/DIAGRAMAS-ANALISIS/DIAGRAMAS/05-actividades/M%C3%B3dulo%20tareas%20Digitales/Diagrama%20de%20Actividades%20%E2%80%94%20Procesamiento%20de%20resultados.jpeg).

**Secuencia:** recibir eventos y condiciones → [validar suficiencia](suficiencia.md) → aplicar solo fórmula de tarea aprobada → guardar valor/unidad con estudiante, tarea, sesión, fecha, versión de configuración y regla → permitir rastrear eventos originarios → presentar al docente. Entradas: ensayos, respuestas/tiempos y condiciones del [modelo de tareas](../../tareas/domain-model.md); fórmulas/denominadores en [modelo de evolución](../domain-model.md). **Alterno:** registros inválidos, incompletos o denominador cero → estado no disponible con motivo, no cero artificial. **Verificación:** conjuntos con resultado de referencia y tolerancia *a definir* coinciden; recalcular misma sesión no duplica resultados; práctica/cierre no calculan indicador cognitivo. Pruebas por TG-01…05, incidente técnico, faltantes y versión distinta. ERD 1:1 sesión-indicador contradice multiplicidad: [pendientes](../../../unresolved-issues.md). Sin endpoint de cálculo documentado.
