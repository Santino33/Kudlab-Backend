# TG-05: La doble misión (~3–4 min)

## Responsabilidad local y externa

**Ficha metodológica, no juego implementado aquí.** El servicio externo ejecuta Cuenta, Vigila y condición dual; Tareas conserva datos diferenciados; Evolución evalúa comparabilidad, precisión/cambio/costo por demanda. No mezclar las dos condiciones individuales en una referencia global.

**Datos necesarios para acordar:** sesión/condición/demanda/ensayo, estímulos/respuestas/tiempos, dificultad/frecuencia, configuración e incidencias. El formato debe identificar ambas referencias y dual; un único porcentaje de sesión no permite reconstruir ese análisis.

**Verificación backend:** referencia ausente, denominador cero y dificultad incompatible no producen DTC validado; conservar valores aislados disponibles cuando proceda. Aprobar fórmula por métrica antes de usar una expresión de precisión para tiempos. El juego y su simultaneidad se prueban externamente. Ver [integración](../../../games-integration.md), [modelo de indicadores](../../evolucion/domain-model.md).

## Mecánica y evidencia original (servicio de juegos)

**Objetivo:** comparar desempeño del mismo estudiante con demandas individuales y simultáneas, sin clasificar «atención dividida normal/deficiente». [F ficha TG-05 pp. 35–38, §5.9 pp. 48–49](../../../../original/Fundamento%20teorico.docx.pdf).

**Flujo:** 1) «Cuenta»: operaciones matemáticas simples, registrar precisión/tiempo; 2) «Vigila»: detectar objetivos visuales intermitentes, registrar detecciones/omisiones/falsas alarmas/TR; 3) «La doble misión»: responder a ambas demandas simultáneas; 4) comparar cada desempeño individual con su dimensión dual. Mantener dificultad/frecuencia comparable, complejidad matemática baja. **Datos:** operaciones/respuestas y tiempos; objetivos visuales/detecciones/omisiones/falsas alarmas/TR; condición, ensayo, dificultad, marca temporal y dispositivo. **Indicadores:** precisión matemática=correctas/ítems válidos ×100; visual=detectados/objetivos válidos ×100; diferencia entre condiciones; costo DTC=(individual−dual)/individual ×100 solo si base distinta de cero y métrica comparable; variabilidad si suficiente. [F §5.9](../../../../original/Fundamento%20teorico.docx.pdf).

**Verificación:** tres condiciones distinguibles; resultado dual sin referencia individual se marca no comparable; cero basal o incidencia no produce DTC espurio; resultados por demanda no se mezclan. Pruebas: ambas referencias y dual completas, falta Vigila, denominador cero, desconexión, diferencias de dificultad.
