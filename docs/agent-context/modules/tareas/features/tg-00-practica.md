# TG-00: práctica guiada (~2 min)

**Propósito:** familiarizar al estudiante con la interfaz y consigna, sin medir memoria/atención. Actor: estudiante con sesión habilitada; Kud guía con instrucción breve visual/auditiva. [F ficha TG-00 pp. 23–25, §3.3.1 p. 17](../../../../original/Fundamento%20teorico.docx.pdf), [flujo general](../../../../original/DIAGRAMAS-ANALISIS/DIAGRAMAS/05-actividades/M%C3%B3dulo%20tareas%20Digitales/Flujo%20general%20del%20modulo%20de%20tareas%20digitales.jpeg).

**Pasos:** instrucción → ejemplo interactivo de Kud de cada tipo de actividad → alumno interactúa → feedback inmediato → confirmar comprensión → comenzar TG-01. Si no comprende, repetir ejemplo (el diagrama retorna a TG-00); no hay máximo de repeticiones definido. **Variables:** intentos/errores/tiempo de práctica, finalización, interacción, dispositivo, sesión; posibles estados de familiarización, repetición y problemas de interfaz. Ninguno es indicador cognitivo y errores de práctica no entran al cálculo. **Aceptar/probar:** sin confirmación no pasar a medición; errores de práctica excluidos de TG-01…05; repetición no clasifica alumno; problemas de audio/interfaz conservan contexto. Dependencias [ejecución](ejecucion.md), [modelo](../domain-model.md). Política ante imposibilidad de comprensión pendiente.
